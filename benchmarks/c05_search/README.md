# C05 local search benchmarks

Synthetic, labeled cases. Measurements are for this process and machine only.
They are not a speed or quality claim for other equipment.

- `weak_conditional_predictor.py` — a moderator with weak marginal correlation that is still generated by diverse approximate search (not dropped by a top-N |corr| cut).
- `profile_runner.py` — records elapsed time and RSS before/after `search_models` on a small exact space.

Do not publish percentage speedups from these scripts.
