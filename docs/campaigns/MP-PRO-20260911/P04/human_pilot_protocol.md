# Protocolo de piloto humano (5–10 avaliações reais autorizadas)

STATUS=NOT_RUN

Este arquivo é o protocolo. Não é um relatório de execução. Nenhum caso
real de cliente foi solicitado, extraído ou avaliado nesta campanha.

## Quando houver autorização

Recrutar 5 a 10 avaliações reais já autorizadas para este trabalho (não
buscar inbox, pastas pessoais nem amostras fora do escopo). Para cada
caso registrar:

1. Situação inicial (tipologia, qualidade da planilha, grau desejado).
2. Tempo ativo do profissional (relógio humano, não o do robô).
3. Retrabalho: campos redigitados, exclusões justificadas, correções editoriais.
4. Limitações encontradas (unidade, data, categoria ausente, extrapolação).
5. Discrepâncias entre o produto e o julgamento do avaliador.
6. Revisão do profissional: o resultado é útil, incompleto ou inaceitável?

## O que este protocolo não mede

- Tempo de cálculo da máquina.
- Tempo de navegação automatizada (Playwright / script).
- Número de cliques de robô.

Essas métricas existem no runner P04 e **não** se convertem em economia
de horas do avaliador.

## Bloqueio

A ausência de casos reais **não** bloqueia o incremento sintético. Ela
limita conclusões sobre mercado e produtividade humana. Prontidão
absoluta não é conclusão deste lote.
